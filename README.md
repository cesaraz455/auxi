# auxi

**auxi** es un pequeño robot de fútbol para una competencia universitaria de robots, un proyecto de primer semestre. Este repositorio contiene el diseño en KiCad de su única PCB.

Toda la documentación del proyecto (decisiones de diseño, alimentación, pines, conectores, chasis, armado de la placa y puntos abiertos) está en un solo archivo: **[`CLAUDE.md`](CLAUDE.md)**.
